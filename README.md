# Phylogeny: Consumption Core

>C0RE Protocol: Create. Explore. Consume. Evolve. Die. Repeat.

## 🧬 Project Overview
**Phylogeny: Consumption Core** is a Bio-Punk 3D ARPG that fuses Metroidvania-style interconnected exploration with Rogue-lite exploration and progression. 

You play as one of five different human colonists living in Luna Novum. 

The first is [[The Mechanic]]. Upon meeting with the other crewmates, the Mechanic discovers that their daughter, now referring to herself as Erica, is unwittingly the leader of a faction of sentient nanites endemic to Enceladus.
